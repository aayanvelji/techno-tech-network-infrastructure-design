The submitted university assignment report is the source for design descriptions, address tables, configuration examples and team task allocation. Internal inconsistencies are identified rather than silently corrected. The Packet Tracer simulation has not been independently tested as part of this documentation update.

Passwords, email/FTP/IoT credentials, wireless passphrases and student IDs are not published. The repository is intentionally image-free.
