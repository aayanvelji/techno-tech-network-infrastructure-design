# Techno Tech – Proposed Network Design

A university group project focused on designing and documenting a multi-branch enterprise network for the fictional organisation **Techno Tech**.

## Project overview

The assignment models a company with branch networks in **Malaysia, Singapore, Australia, and Japan**. The design covers branch LANs, IP addressing, WAN connectivity, network-device configuration, and shared network services.

The implementation artefact is a Cisco Packet Tracer project. The accompanying assignment report documents the design decisions, addressing plans, configurations, and testing.

## Project scope

- Branch LAN topology and floor-plan design
- IP addressing and subnet planning
- WAN connectivity between branches, including a mesh design
- Router and switch configuration
- Network services such as DNS, web, FTP, email, and IoT where implemented
- Wireless access and end-device connectivity
- Configuration and connectivity verification

> The exact technologies and implemented features will be documented against the supplied report and Packet Tracer file. This README will be refined as the repository is populated.
